# Smart Wholesale Management - Farhan

## Project files
- `index.html` — main app structure
- `css/style.css` — extracted CSS
- `js/app.js` — extracted JavaScript
- `assets/` — reserved for images and icons
- `vercel.json` — static deployment configuration

## Deploy
1. Upload these files/folders to a GitHub repository.
2. Import that repository into Vercel.
3. Choose the `Other` framework preset.
4. Leave Build Command and Output Directory empty, then deploy.

This is a static browser app. As in the source file, data is stored in the current browser's localStorage; it does not automatically sync between devices.
